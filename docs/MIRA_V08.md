# KEIRIN LAB v0.8: 日次出走表を自動で取り込むアダプタ

## 実装済み

- 公開GitHubの`snarfnet/keirin-data`が公開している日次`entries_YYYYMMDD.json`と互換のアダプタを実装
- 日次1ファイルだけ取得（1時間の最低取得間隔）、最大2MB、タイムアウト15秒
- 日本時間の今日の日付を自動指定。発走まで30分以上残るレースから最大3件を選択
- 選手名、車番、競走得点、勝率（%→小数）、2連対率（%→小数）、脚質、発走予定時刻を保存
- 記録日時は**実際にHTTP応答を受けた時点**。発走後に取得したデータを予測用に挿入しない
- 同じレースが既存DBにあれば上書きしない。予測作成途中で失敗した場合だけ発走前に比較予測を再試行
- 出走表の保存時点で既存の単純比較モデル（Plackett-Luce）を発走前に凍結
- 登録できた場合に静的HTMLを自動再生成。CGIではDBを随時参照
- 実戦レース、デモ、結果、MIRAの独自予想は混在させない

**注意:** この外部リポジトリには明示的なデータ再利用ライセンスが確認できていません。公開GitHubで読めることと複製・継続蓄積の許可は別です。運用者が情報提供元および二次配信元の利用条件を確認し、適切な許可・権利を持つ場合のみ`--source-rights-confirmed`を指定してください。このスイッチ自体が権利を付与するものではありません。**自動実行はまだ設置・有効化していません。**

## 使い方（利用条件の確認後）

```bash
cd /home/dsktnk/www/keirin
git pull origin main

# さくらから今日の日次データを1件のHTTPSリクエストで取得・登録
/usr/local/bin/python tools/ingest_daily.py --fetch-today --source-rights-confirmed
```

- 初期状態では近い将来の最大3レースのみ登録。途中で中断しても既登録データは上書きしない
- 取得後に`research.html`を自動生成。CGIでは`index.cgi?view=research`
- このコマンドは**MIRAの買い目を生成しません**。既存の比較用数理モデルだけを凍結します。私が会話で予想した買い目は`tools/real_race.py predict`で別途保存します
- 当日分がなくても、数値の補完や前日分の転用は行いません

### 書き込みなしの動作確認（サーバー通信あり）

```bash
/usr/local/bin/python tools/ingest_daily.py --fetch-today --source-rights-confirmed --dry-run
```

### 外部通信を行わないJSON読込検証

```bash
/usr/local/bin/python tools/ingest_daily.py --file ./local/source_entries.json --dry-run
```

`source_entries.json` は手元に存在する同形式ファイルを指します。自動生成しません。

### 将来の自動実行例（実運用の許可確認と手動テストが終わってから）

さくらでのcron構成例。標準が日本時間のサーバーの場合。実際にインストール・スケジュール登録はしていません。

```crontab
15 9-21/2 * * * cd /home/dsktnk/www/keirin && /usr/local/bin/python tools/ingest_daily.py --fetch-today --source-rights-confirmed >> data/dailyfeed.log 2>&1
```

自動実行の前に、提供元の更新頻度、アクセス間隔、公開利用条件、時間帯、cron実行ユーザーのDB/HTMLへの書込権限を確認してください。取得先が403、429、404の場合はその回を失敗として終了し、制限回避や迂回アクセスは行いません。

## 利用データの限界

- フィード内に実証済みの**ライン識別子がない**ため `line_id=""` とする。勝手に選手コメントからラインを作らない
- グレードやクラス名称も確実な欄がなければ空欄
- 結果、払い戻し、当日のオッズは本アダプタから登録しない
- 第三者データの内容が公式の確定出走表と異なる場合がある。結果を利用する前に原資料と照合する
- 競走中止・欠場・発走時刻変更が生じた場合、登録済みの確率を後から書き換えない。別の変更履歴管理が必要
- モデルは未学習、確率較正未実施。買い目として有利とは限らない
